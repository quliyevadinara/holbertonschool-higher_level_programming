# Python - More Data Structures: Set, Dictionary

This project covers more Python data structures, focusing on sets and dictionaries, as well as lambda functions and the use of `map`.

## Learning Objectives

- What are sets and how to use them
- What are the most common methods of sets and how to use them
- When to use sets versus lists
- How to iterate into a set
- What are dictionaries and how to use them
- When to use dictionaries versus lists or sets
- What is a key in a dictionary
- How to iterate over a dictionary
- What is a lambda function
- What are the `map`, `reduce`, and `filter` functions

## Tasks

### 0. Squared simple

**File:** `0-square_matrix_simple.py`

Returns a new matrix with each value squared. The original matrix is not modified.

### 1. Search and replace

**File:** `1-search_replace.py`

Returns a new list with all occurrences of a given element replaced by another.

### 2. Unique addition

**File:** `2-uniq_add.py`

Returns the sum of all unique integers in a list (each integer counted only once).

### 3. Present in both

**File:** `3-common_elements.py`

Returns a set of common elements found in two sets.

### 4. Only differents

**File:** `4-only_diff_elements.py`

Returns a set of all elements present in only one of the two sets.

### 5. Number of keys

**File:** `5-number_keys.py`

Returns the number of keys in a dictionary.

### 6. Print sorted dictionary

**File:** `6-print_sorted_dictionary.py`

Prints a dictionary with keys sorted in alphabetical order.

### 7. Update dictionary

**File:** `7-update_dictionary.py`

Replaces or adds a key/value pair in a dictionary.

### 8. Simple delete by key

**File:** `8-simple_delete.py`

Deletes a key from a dictionary. If the key doesn't exist, the dictionary is unchanged.

### 9. Multiply by 2

**File:** `9-multiply_by_2.py`

Returns a new dictionary with all integer values multiplied by 2.

### 10. Best score

**File:** `10-best_score.py`

Returns the key with the biggest integer value in a dictionary. Returns `None` if the dictionary is empty or `None`.

### 11. Multiply by using map

**File:** `11-multiply_list_map.py`

Returns a new list with all values multiplied by a number, using `map`. Maximum 3 lines.

### 12. Roman to Integer

**File:** `12-roman_to_int.py`

Converts a Roman numeral string to an integer. Returns `0` if the input is not a string or is `None`. Handles values from 1 to 3999.

## Requirements
