# JavaScript DOM Manipulation

This project contains basic JavaScript DOM manipulation exercises.

## Tasks

0. **Color Me**  
   Change the `<header>` text color to red using `document.querySelector`.

1. **Click and turn red**  
   Change the `<header>` text color to red when clicking `#red_header`.

2. **Add `.red` class**  
   Add class `red` to `<header>` when clicking `#red_header`.

3. **Toggle classes**  
   Toggle `<header>` class between `red` and `green` when clicking `#toggle_header`.

4. **List of elements**  
   Add `<li>Item</li>` to `.my_list` when clicking `#add_item`.

5. **Change the text**  
   Set `<header>` text to `New Header!!!` when clicking `#update_header`.

6. **Star Wars character**  
   Fetch and display character name in `#character`.

7. **Star Wars movies**  
   Fetch and list all movie titles in `#list_movies`.

8. **Say Hello!**  
   Fetch “hello” translation and display in `#hello`.
