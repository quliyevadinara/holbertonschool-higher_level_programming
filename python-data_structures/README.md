# Python - Data Structures: Lists, Tuples

This project covers Python data structures, focusing on lists and tuples, including how to access, modify, and manipulate them.

## Learning Objectives

- What are lists and how to use them
- What are the differences and similarities between strings and lists
- What are the most common methods of lists and how to use them
- How to use lists as stacks and queues
- What are list comprehensions and how to use them
- What are tuples and how to use them
- When to use tuples versus lists
- What is a sequence
- What is tuple packing and sequence unpacking
- What is the `del` statement and how to use it

## Tasks

### 0. Print a list of integers

**File:** `0-print_list_integer.py`

Prints all integers of a list, one per line, using string format.

### 1. Secure access to an element in a list

**File:** `1-element_at.py`

Retrieves an element from a list by index. Returns `None` if index is negative or out of range.

### 2. Replace element

**File:** `2-replace_in_list.py`

Replaces an element at a specific position in a list. Returns the original list unchanged if index is invalid.

### 3. Print a list of integers... in reverse!

**File:** `3-print_reversed_list_integer.py`

Prints all integers of a list in reverse order, one per line, using string format.

### 4. Replace in a copy

**File:** `4-new_in_list.py`

Replaces an element at a specific position in a copy of the list, without modifying the original.

### 5. Can you C me now?

**File:** `5-no_c.py`

Returns a new string with all `c` and `C` characters removed, without using `str.replace()`.

### 6. Lists of lists = Matrix

**File:** `6-print_matrix_integer.py`

Prints a matrix of integers using `str.format()`.

### 7. Tuples addition

**File:** `7-add_tuple.py`

Adds two tuples element by element and returns a tuple of 2 integers. Handles tuples shorter or longer than 2.

### 8. More returns!

**File:** `8-multiple_returns.py`

Returns a tuple containing the length of a string and its first character. Returns `None` as first character if the string is empty.

### 9. Find the max

**File:** `9-max_integer.py`

Finds the biggest integer in a list without using the built-in `max()`. Returns `None` for an empty list.

### 10. Only by 2

**File:** `10-divisible_by_2.py`

Returns a new list of `True`/`False` values indicating whether each element in the original list is a multiple of 2.

### 11. Delete at

**File:** `11-delete_at.py`

Deletes an item at a specific position in a list without using `pop()`. Returns the list unchanged if index is invalid.

### 12. Switch

**File:** `12-switch.py`

Switches the values of variables `a` and `b` in exactly 5 lines.
