# Python - if/else, loops, functions

Bu layihədə müxtəlif Python tapşırıqları icra olunub:

## Tapşırıqlar:
- **0-positive_or_negative.py** - Rəqəmin müsbət, mənfi və ya sıfır olmasını yoxlayır.
- **1-last_digit.py** - Rəqəmin sonuncu rəqəmini yoxlayır və xüsusiyyətini çap edir.
- **2-print_alphabet.py** - İngilis əlifbasını kiçik hərflərlə çap edir.
- **3-print_alphabt.py** - İngilis əlifbasını q və e hərfi olmadan çap edir.
- **4-print_hexa.py** - 0-dan 98-ə qədər ədədləri onluq və onaltılıq şəkildə çap edir.
- **5-print_comb2.py** - 0-dan 99-a qədər olan iki rəqəmli ədədləri vergüllə ayırıb çap edir.
- **6-print_comb3.py** - İki fərqli rəqəmin bütün kombinasiyalarını çap edir.
- **7-islower.py** - Hərfin kiçik olub olmadığını yoxlayan funksiya.
- **8-uppercase.py** - Verilən sətiri böyük hərflə çap edən funksiya.
- **9-print_last_digit.py** - Verilmiş ədəddə ən son rəqəmi qaytaran funksiya.
- **10-add.py** - İki ədədin cəmini qaytaran funksiya.
- **11-pow.py** - Bir ədədin qüvvətini qaytaran funksiya.
- **12-fizzbuzz.py** - 1-dən 100-ə qədər "FizzBuzz" oyununu çap edən funksiya.

## İstifadə Qaydası:
Faylları icra üçün aşağıdakı əmri istifadə et:
```bash
./filename.py
```

## İcra icazəsi vermək (chmod):
Bütün skriptlərə icra icazəsi vermək üçün:
```bash
chmod +x *.py
```
